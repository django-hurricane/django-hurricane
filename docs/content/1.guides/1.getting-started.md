# Getting Started

Getting started with Django Hurricane takes less than two minutes.

---

## 1. Installation

Install Hurricane using **[Astral uv](https://github.com/astral-sh/uv)** (recommended) or standard `pip`:

```bash [uv]
uv add django-hurricane
```

```bash [pip]
pip install django-hurricane
```

---

## 2. Configure Django `settings.py`

Add `"hurricane"` to your `INSTALLED_APPS`:

```python [settings.py]
INSTALLED_APPS = [
    # Standard Django apps...
    "django.contrib.admin",
    "django.contrib.auth",
    "django.contrib.contenttypes",
    "django.contrib.sessions",
    "django.contrib.messages",
    "django.contrib.staticfiles",
    # Add Hurricane:
    "hurricane",
]
```

---

## 3. Launching the Server

Run the `serve` management command:

```bash
python manage.py serve
```

## 4. Verifying Endpoints

Open a new terminal window to test your endpoints:

### Application Traffic (Port 8000):
```bash
curl http://localhost:8000/
# Returns your Django application's root view
```

### Kubernetes Health Probes (Port 8001):
```bash
curl http://localhost:8001/alive
# Returns: alive (HTTP 200 OK)

curl http://localhost:8001/ready
# Returns: OK (HTTP 200 OK)

curl http://localhost:8001/startup
# Returns: Startup was finished ... (HTTP 200 OK)
```

### Prometheus Metrics (Port 8001):
```bash
curl http://localhost:8001/metrics
# Returns Prometheus metric exposition:
# request_counter 1.0
# response_time_average 2.15
# request_queue_length 0
```
